# Titanic Survival Prediction

## Overview
This project predicts whether a passenger survived the Titanic disaster using Machine Learning. The model is trained on the Titanic dataset after data preprocessing and feature engineering.

## Features
- Data preprocessing
- Missing value handling
- Feature engineering
- Model training
- Survival prediction
- Model evaluation

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Dataset
The dataset used in this project is the Titanic dataset from the Kaggle Titanic Machine Learning Competition.

## Project Structure
```
Titanic-Survival-Prediction/
│── Titanic_ML_Project.ipynb
│── app.py
│── titanic.csv
│── requirements.txt
│── HOW_TO_RUN.md
```

## Installation

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
python app.py
```

## Machine Learning Workflow
- Import dataset
- Clean data
- Feature selection
- Train the model
- Test the model
- Predict passenger survival
